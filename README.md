## Course group project: social media usage analysis

The original Canvas assignment describes a group project using **Google Forms** to collect survey responses and **StatCrunch** to analyze Instagram and YouTube usage. Students collect at least 20 responses for the survey component and use the instructor-provided dataset for the remaining analyses.

The project applies:

- Histograms and boxplots to describe distributions and outliers.
- Conditional probabilities and comparisons between groups.
- Confidence intervals and hypothesis tests for proportions and means.
- Comparisons of weekly time spent on the two platforms.
- A contingency table and chi-square test of independence.
- Scatterplots and a test of linear correlation.

**Repository scope:** The group-project report, survey responses, StatCrunch outputs, and instructor-provided project spreadsheet are not present here. This section describes the course assignment, not a completed project included in this repository.
